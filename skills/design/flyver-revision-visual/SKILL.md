# Revisión visual

1. Identifica el dispositivo, tamaño de viewport y tarea esperada. Revisa la versión actual y compara solo con referencias que correspondan.
2. Mira primero recortes, desbordes, acciones ocultas y legibilidad. Después revisa jerarquía, alineación y consistencia con componentes existentes.
3. Si puedes interactuar, prueba teclado, foco visible, errores y vuelta atrás. Si solo hay captura, marca esos comportamientos como no verificables.
4. Ordena hallazgos por impacto. Cada uno necesita vista o estado, evidencia, consecuencia y corrección concreta. No confundas preferencia estética con defecto reproducible.

Entrega primero el bloqueo más costoso, luego los refinamientos. Evita reabrir decisiones visuales aprobadas sin nueva evidencia.
