# Agent Skills de Flyver

- Cada skill vive en `skills/<tema>/<nombre>/SKILL.md`. Mantén nombres únicos, metadata breve y reglas específicas de la tarea. Lee solo las referencias necesarias.
- Antes de agregar o cambiar una skill, lee [CONTRIBUTING.md](CONTRIBUTING.md). Corre `npm run check` y `npm test`.
- No agregues credenciales, datos reales de clientes, contenido sin permiso ni copias de instrucciones internas de un proveedor. Una skill no autoriza publicación, envío, gasto ni cambios de producción.
- No instales en otros proyectos como efecto de validar este repositorio.
